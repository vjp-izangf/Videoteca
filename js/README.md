# VideoGameLibrary

Videoteca de videojuegos.

## Descripción

Aplicación sencilla para gestionar una colección de videojuegos.

## Campos

Cada videojuego contiene:

- ID
- Título
- Género
- Plataforma
- Desarrollador
- Fecha de lanzamiento
- Precio

## Estructura

- `index.html`: estructura de la página.
- `js/app.js`: datos de los videojuegos.
- `README.md`: información del proyecto.
